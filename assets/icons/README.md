# Technology logos

These local SVGs keep the profile's technology logos available without an external image service.

- All icons except `bulma.svg`, `expo.svg`, and `render.svg` come from [Skill Icons](https://github.com/tandpfun/skill-icons/tree/main/icons). The original filenames use the dark theme where available. The MIT license is included in `LICENSE-skill-icons.txt`.
- The Bulma, Expo, and Render paths come from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons), placed on matching rounded backgrounds. The CC0 dedication is included in `LICENSE-simple-icons.txt`.
- React Native uses the existing React icon. Its README label and tooltip identify React Native.

The initial icons were retrieved on October 29, 2026. Java, Python, Expo, Android Studio, Three.js, and jQuery were added on November 4, 2026. Neutral tile backgrounds match the portfolio's charcoal surface. Brand marks identify the technologies used; their respective owners retain their trademark rights.
