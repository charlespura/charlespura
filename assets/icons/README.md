# Technology logos

These local SVGs keep the profile's technology logos available without an external image service.

- All icons except `bulma.svg` and `render.svg` come from [Skill Icons](https://github.com/tandpfun/skill-icons/tree/main/icons). The original filenames use the dark theme where available. The MIT license is included in `LICENSE-skill-icons.txt`.
- The Bulma and Render paths come from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons), placed on matching rounded backgrounds. The CC0 dedication is included in `LICENSE-simple-icons.txt`.
