## About me

I'm a **full-stack developer from Quezon City, Philippines**, and a **BSIT graduate, Cum Laude**, majoring in Information Management at Bestlink College of the Philippines.

My projects span adoption management, reporting automation, personal finance, and productivity. I like connecting a clear interface with the logic and data behind it, and learning by building complete applications.

- **Web development:** responsive interfaces, application workflows, APIs, and databases.
- **Exploring:** mobile app development and ways to make applications more useful and intuitive.
- **Open to:** project collaboration, mentorship, and conversations with other developers.
